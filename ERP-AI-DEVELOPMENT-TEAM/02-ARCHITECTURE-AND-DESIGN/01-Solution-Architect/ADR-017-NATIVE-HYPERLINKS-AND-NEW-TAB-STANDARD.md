## ১. ব্যবসায়িক প্রেক্ষাপট ও সমস্যা (Business Context & Problem Statement)

তৈরি পোশাক কারখানার (RMG/Apparel ERP) বাস্তব ফ্লোরে একজন ব্যবহারকারী (যেমন: সিনিয়র মার্চেন্ডাইজার, কস্টিং ম্যানেজার, বা ফ্লোর প্ল্যানার) কখনই ব্রাউজারে সিঙ্গেল স্ক্রিন নিয়ে কাজ করেন না। তাদের কাজের ধরন মাল্টি-টাস্কিং:
1. **তুলনামূলক বিশ্লেষণ (Comparative Analysis):** মার্চেন্ডাইজার একটি ট্যাবে বায়ারের "Buyer Order List" খুলে রেখে, একই সাথে ৫টি ভিন্ন স্টাইলের (Style Details) লিংক **Mouse Right-Click -> "Open link in new tab"** অথবা মাউসের **Middle-Click** (মাউস হুইল ক্লিক) করে ৫টি আলাদা ব্রাউজার ট্যাবে ব্যাকগ্রাউন্ডে খুলে রাখেন।
2. **কাজ না হারানো (Context Loss Prevention):** একটি ৬০-৭০ রো বিশিষ্ট কাটিং শিট বা ফেব্রিক ইনভেন্টরি পেজ ফিল্টার করা অবস্থায় ব্যবহারকারী কোনো রো-তে ক্লিক করলে যদি পেজটি স্টেট হারিয়ে বর্তমান ট্যাবেই ওভাররাইট হয়, তবে আগের ফিল্টার করা ডাটা হারিয়ে যায়।
3. **এন্টারপ্রাইজ এসপিএ (SPA) সমস্যা:** অধিকাংশ সাধারণ রিঅ্যাক্ট অ্যাপ্লিকেশনে ডেভেলপাররা নেভিগেশনের জন্য সাধারণ `<div onClick={...}>` বা `<button onClick={...}>` ব্যবহার করেন। এর ফলে ব্রাউজারের নেটিভ বিহেভিয়ার যেমন: **Right-Click -> "Open in new tab"**, **Ctrl + Click**, কিংবা **Middle-Click** সম্পূর্ণ নষ্ট হয়ে যায় এবং ব্যবহারকারী বিরূপ অভিজ্ঞতার সম্মুখীন হন।

## ২. মূল আর্কিটেকচারাল সিদ্ধান্ত (The Architectural Decision)

> 🛑 **MANDATORY INVARIANT [INVARIANT-23]:**  
> TraceFlow-RMG প্ল্যাটফর্মের যেকোনো পেজ, রেকর্ড, টেবিল রো বা মেন্যু আইটেম—যা অন্য কোনো স্ক্রিন, মডিউল বা বিস্তারিত তথ্যে নিয়ে যায়—তাতে কৃত্রিম `onClick` নেভিগেশনের পরিবর্তে **১০০% বৈধ নেটিভ হাইপারলিংক (`<a href="...">` / Semantic Link Component)** ব্যবহার করতে হবে।

### ২.১ মাল্টি-ট্যাব শেয়ার্ড অথেন্টিকেশন নীতি (Multi-Tab Auth State Synchronization)
* নতুন ট্যাবে যখনই কোনো লিংক ওপেন হবে (`Open link in new tab`), তখন নতুন ট্যাব যাতে লগআউট না দেখায় সেজন্য সেশন এবং টোকেন **`localStorage` ও ব্রাউজার কুকি**-তে নিরাপদে সংরক্ষিত থাকতে হবে।
* Zustand স্টোর ইনিশিয়ালাইজেশনের সময় লোকাল স্টোরেজ থেকে বিদ্যমান টোকেন পড়ে ইনস্ট্যান্ট অথেন্টিকেশন স্টেট রিস্টোর করবে।

### ২.২ রি-ইউজেবল `<Link />` ও ক্লিকেবল রো প্যাটার্ন (Clickable Row with Real Link)
টেবিল বা লিস্টের ক্ষেত্রে নিচের কোডিং প্যাটার্ন বাধ্যতামূলক:

```tsx
// ❌ সম্পূর্ণ নিষিদ্ধ (ব্রাউজার রাইট-ক্লিক বা নিউ-ট্যাব সাপোর্ট করে না):
<tr onClick={() => navigate(`/app/orders/${order.id}`)}>
  <td>{order.code}</td>
  <td>{order.buyer_name}</td>
</tr>

// ✅ অনুমোদিত এন্টারপ্রাইজ প্যাটার্ন (নেটিভ লিংক যা রাইট-ক্লিক ও মিডল-ক্লিক সাপোর্ট করে):
<tr>
  <td>
    <a 
      href={`/app/orders/${order.id}`}
      className="tf-table-link"
      onClick={(e) => {
        // যদি সাধারণ লেফট-ক্লিক হয় এবং কোনো মডিফায়ার কি (Ctrl/Cmd) না থাকে, তবে SPA নেভিগেশন
        if (!e.ctrlKey && !e.metaKey && e.button === 0) {
          e.preventDefault();
          navigateTo(`/app/orders/${order.id}`);
        }
        // অন্যথায় (Right-click, Ctrl+Click, Middle-click) ব্রাউজারের নেটিভ বিহেভিয়ার স্বতঃস্ফূর্তভাবে কার্যকর হবে
      }}
    >
      {order.code}
    </a>
  </td>
  <td>{order.buyer_name}</td>
</tr>
```

## ৩. স্ট্যান্ডার্ড ইউআরএল স্ট্রাকচার (Predictable Deep-Linking Routes)

প্রতিটি এন্টারপ্রাইজ রিসোর্সের জন্য একটি স্পষ্ট ও অনুমেয় নেটিভ ইউআরএল থাকতে হবে, যাতে সরাসরি যেকোনো ট্যাবে পেস্ট করলেও রিসোর্সটি ওপেন হয়:

| রিসোর্স / মডিউল | ক্লিকেবল এলিমেন্ট | স্ট্যান্ডার্ড ইউআরএল পাথ (`href`) |
|---|---|---|
| **Company Directory** | Company Code / Name | `/app/companies/{companyId}` |
| **Buyer Directory** | Buyer Code / Name | `/app/buyers/{buyerId}` |
| **Buyer Orders** | Order / PO Number | `/app/orders/{orderId}` |
| **Style Master** | Style Code | `/app/styles/{styleId}` |
| **Cutting Job** | Cut Plan No | `/app/cutting/{cutJobId}` |
| **Bundle Barcode** | Bundle No | `/app/bundles/{bundleBarcode}` |
| **Sewing Daily Line** | Line No | `/app/production/lines/{lineId}` |
| **Platform Tenant** | Holding Group Slug | `/platform/tenants/{tenantId}` |

## ৪. কারিগরি প্রভাব ও ইতিবাচক দিক (Consequences & Benefits)

1. **ফ্যাক্টরি মার্চেন্ডাইজারদের সর্বোচ্চ গতি:** ব্যবহারকারী তার প্রয়োজনমতো যত ইচ্ছা ট্যাব খুলে পাশাপাশি তুলনা করতে পারবেন।
2. **ব্রাউজার ব্যাক/ফরোয়ার্ড হিস্ট্রি অক্ষুণ্ণ:** ব্রাউজারের ব্যাক বাটন চাপলে আগের পেজের ফিল্টার ও স্ক্রোল পজিশন সঠিক থাকবে।
3. **বুকমার্কিং ও লিংক শেয়ারিং:** একজন মার্চেন্ডাইজার একটি নির্দিষ্ট স্টাইলের লিংক সরাসরি কপি করে স্কাইপ/হোয়াটসঅ্যাপ বা ইন্টারনাল মেসেঞ্জারে ফ্লোর ম্যানেজারের সাথে শেয়ার করতে পারবেন, এবং লিংকে ক্লিক করলেই সরাসরি ঐ স্টাইলের পেজ ওপেন হবে।
4. **জিরো স্টেট করাপশন:** প্রতিটি ট্যাব স্বাধীনভাবে তার নিজস্ব রিঅ্যাক্ট স্টেট ও ডাটা ফেচিং মেইনটেইন করবে; একটি ট্যাবের ফর্ম এডিট অন্য ট্যাবের কাজে কোনো বাধা সৃষ্টি করবে না।
