## ১. ভূমিকা ও ইন্টিগ্রেশনের পরিধি (Integration Mission)

TraceFlow-RMG প্ল্যাটফর্মটি বিচ্ছিন্ন কোনো দ্বীপ নয়। এটি কারখানার আধুনিক যন্ত্রপাতি (হার্ডওয়্যার বারকোড স্ক্যানার, ডিজিটাল ওজন স্কেল, সিএডি প্যাটার্ন সফটওয়্যার) এবং বহিরাগত এন্টারপ্রাইজ সিস্টেমের (সাপ্লাই চেইন ইআরপি, কমার্শিয়াল অ্যাকাউন্টিং এবং বায়ারের ইডিআই সিস্টেম) সাথে রিয়েল-টাইমে ডাটা আদান-প্রদান করে।

এই নথির উদ্দেশ্য হলো নিরাপদ, আইডিমপোটেন্ট (Idempotent) এবং উচ্চগতির ইন্টিগ্রেশন প্রটোকল সংজ্ঞায়িত করা।

  ```json
  }
  ```

## ৩. থার্ড-পার্টি ইআরপি ও বায়ার ইডিআই ইন্টিগ্রেশন (External ERP & Webhooks)

### ৩.১ আইডিমপোটেন্ট ওয়েবহুক প্রটোকল (Idempotent Webhook Architecture)
বায়ারের অর্ডার কনফার্মেশন বা সাপ্লাই চেইন আপডেট গ্রহণের জন্য সিস্টেম একটি নিরাপদ ওয়েবহুক রিসিভার পরিচালনা করবে:

1. **সিগনেচার ভেরিফিকেশন (HMAC-SHA256):**
   - প্রতি ওয়েবহুক রিকোয়েস্টে `X-TraceFlow-Signature` হেডার থাকবে।
2. **আইডিমপোটেন্সি কি (Idempotency Guard):**
   - প্রতি রিকোয়েস্টে ইউনিক `Idempotency-Key` থাকবে যা রেডিসে ২৪ ঘণ্টার জন্য ক্যাশ থাকবে। একই রিকোয়েস্ট দ্বিতীয়বার এলে কোনো ডুপ্লিকেট অর্ডার তৈরি না করে পূর্বের রেসপন্স ক্যাশ থেকে রিটার্ন করবে।

```php
// ✅ আইডিমপোটেন্ট রিসিভার লজিক
$idempotencyKey = $request->header('Idempotency-Key');
if (Cache::has("idemp_{$idempotencyKey}")) {
    return response()->json(Cache::get("idemp_{$idempotencyKey}"), 200);
}

// প্রসেস নতুন অর্ডার...
$response = ['success' => true, 'message' => 'Order synced successfully.'];
Cache::put("idemp_{$idempotencyKey}", $response, now()->addHours(24));
return response()->json($response, 201);
```
