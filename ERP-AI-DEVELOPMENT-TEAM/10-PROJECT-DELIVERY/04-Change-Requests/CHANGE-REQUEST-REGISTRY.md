## ৩. স্ট্যান্ডার্ড সিআর আবেদন ফরম্যাট (CR Submission Form)

```markdown
### Change Request ID: CR-[XXX]
- **Date:** YYYY-MM-DD
- **Requested By:** [Name & Role]
- **Impact Level:** L1 (Low) / L2 (Medium) / L3 (High) / L4 (Hotfix)
- **Change Justification:** [কেন এই পরিবর্তনটি প্রয়োজন?]
- **Affected Artifacts:**
  - [ ] SRS Document updated
  - [ ] ERD / Schema migration file prepared
  - [ ] UI Component updated
- **Rollback Strategy:** [যদি সমস্যা হয় তবে কীভাবে পূর্বের অবস্থায় ফেরা হবে?]
- **CAB Decision:** APPROVED / REJECTED by [Signatures]
```
