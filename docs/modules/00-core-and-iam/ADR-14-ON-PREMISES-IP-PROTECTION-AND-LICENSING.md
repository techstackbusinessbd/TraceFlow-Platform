# TraceFlow-RMG: অন-প্রিমিস আইপি প্রোটেকশন, কোড অবফাসকেশন ও লাইসেন্সিং (ADR-14)
**নথি কোড:** TFRMG-ARCH-ADR-014  
**সংস্করণ:** ১.০.০  
**কার্যকরী তারিখ:** ২৫ সেপ্টেম্বর, ২০২৬  
**শ্রেণীবিভাগ:** ইন্টেলেকচুয়াল প্রপার্টি (IP) সিকিউরিটি, বাইনারি ডিস্ট্রিবিউশন ও হার্ডওয়্যার লাইসেন্সিং  
**অনুমোদনকারী:** ট্রেসফ্লো-আরএমজি প্রিন্সিপাল আর্কিটেকচার ও সিকিউরিটি কাউন্সিল

## ১. প্রসঙ্গ ও সমস্যা বিবৃতি (Context & Problem Statement)
TraceFlow-RMG যখন কোনো গ্রাহকের (Client Factory) নিজস্ব অন-প্রিমিস প্রাইভেট সার্ভারে ডেপ্লয় করা হয়, তখন গ্রাহকের অভ্যন্তরীণ আইটি টিম বা সফটওয়্যার ডেভেলপারদের ওই সার্ভারে রুট অ্যাক্সেস থাকতে পারে।

যদি সাধারণ ডেভেলপমেন্ট প্রজেক্টের মতো ক্লায়েন্টের সার্ভারে কাঁচা পিএইচপি (`.php`) সোর্স কোড বা রিঅ্যাক্ট/টাইপস্ক্রিপ্ট সোর্স ফাইল রাখা হয়:
1. ক্লায়েন্টের ডেভেলপাররা আমাদের সম্পূর্ণ বিজনেস লজিক, আরএমজি অ্যালগরিদম ও সূত্রাবলী রিভার্স ইঞ্জিনিয়ার বা চুরি করতে পারে।
2. কোডবেস অননুমোদিতভাবে মডিফাই করে লাইসেন্স বাইপাস করতে পারে।
3. সম্পূর্ণ সফটওয়্যার কপি করে অন্য কোনো কারখানায় বা ব্যবসায় অবৈধভাবে চালাতে পারে।

অতএব, অন-প্রিমিস ডেপ্লয়মেন্টেও প্ল্যাটফর্ম ওনারের ইন্টেলেকচুয়াল প্রপার্টি (IP) ১০০% সুরক্ষিত রাখার সুস্পষ্ট আর্কিটেকচারাল পলিসি অপরিহার্য।

## ২. গৃহীত সিদ্ধান্ত (Architectural Decisions)

```
┌────────────────────────────────────────────────────────────────────────┐
│             TRACFLOW CLOUD BUILD PIPELINE (Central CI/CD)              │
│                                                                        │
│   [ Raw PHP 8.3 & React Source ] ──► [ Obfuscation & Bytecode Compile ]│
│                                        ├── Yakpro / FrankenPHP Binary  │
│                                        └── Vite Production Minify      │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │ Push Private Image
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│            CLIENT'S ON-PREMISES SERVER (Zero Source Code Exposure)     │
│                                                                        │
│   ├── docker-compose.yml ──► Pulls: registry.traceflow.io/backend:v1  │
│   ├── Hardware Fingerprint ──► CPU ID + Motherboard UUID + MAC Address │
│   └── Signed Cryptographic Key (license.key) ──► Validates Signature   │
└────────────────────────────────────────────────────────────────────────┘
```

### [DECISION-01] জিরো সোর্স কোড ডেলিভারি (Zero Source Code on Client Server)
- ক্লায়েন্টের সার্ভারে কখনোই গিট রিপোজিটরি ক্লোন (`git clone`) করা হবে না বা কোনো কাঁচা `.php` / `.tsx` সোর্স ফাইল দেওয়া হবে না।
- ক্লায়েন্ট শুধুমাত্র আমাদের প্রাইভেট কন্টেইনার রেজিস্ট্রি (`registry.traceflow.io`) থেকে প্রি-বিল্ট ডকার ইমেজ পুল করবে।

### [DECISION-02] ব্যাকএন্ড বাইটকোড কম্পাইলেশন ও অবফাসকেশন (Bytecode Compilation)
- কন্টেইনার বিল্ডের সময় ব্যাকএন্ড কোডকে রিভার্স-ইঞ্জিনিয়ারিং প্রতিরোধী স্তরে রূপান্তর করা হবে:
  - **বাইটকোড প্রি-কম্পাইলেশন / অবফাসকেশন:** ভ্যারিয়েবল, ইন্টারনাল ফাংশন এবং প্রোপার্টি নেমগুলোকে মেশিন-এনকোডেড বাইটকোডে রূপান্তর করা হবে। কন্টেইনারের ভেতরে শেল দিয়ে ঢুকলেও কোনো রিডেবল সোর্স কোড পাওয়া যাবে না।
  - **স্ট্যান্ডঅ্যালোন বাইনারি (FrankenPHP/Swoole):** সম্পূর্ণ লারাভেল কার্নেল একটি এক্সিকিউটেবল বাইনারিতে প্যাক থাকবে।

### [DECISION-03] ফ্রন্টএন্ড অ্যাসেট মিনিট্রিফিকেশন ও সোর্স-ম্যাপ বর্জন (No Source Maps)
- ক্লায়েন্টের ব্রাউজার বা ওয়েব সার্ভারে শুধুমাত্র প্রোডাকশন বান্ডেল (`dist/`) থাকবে।
- প্রডাকশন বিল্ডে কোনো সোর্স ম্যাপ (`.map` files) সরবরাহ করা কঠোরভাবে নিষিদ্ধ। সমস্ত ভ্যারিয়েবল ও মেথড ৩-৪ অক্ষরের মিনিকোড (`a.b()`) এ এনকোডেড থাকবে।

### [DECISION-04] হার্ডওয়্যার-লকড ক্রিপ্টোগ্রাফিক লাইসেন্সিং (Hardware-Bound License)
1. **সার্ভার ফিঙ্গারপ্রিন্ট:** অন-প্রিমিস ইনস্টলেশনের সময় ক্লায়েন্ট সার্ভারের ইউনিক হার্ডওয়্যার ফিঙ্গারপ্রিন্ট সংগ্রহ করা হবে:
   - CPU Processor ID
   - Motherboard Serial Number
   - Primary Network MAC Address
2. **অ্যাসিমেট্রিক ডিজিটাল সাইনিং (RSA-4096 / Ed25519):**
   - প্ল্যাটফর্ম ওনারের প্রাইভেট কি দ্বারা লাইসেন্স ফাইল (`license.key`) সাইন করা হবে (যাতে মেয়াদ, অনুমোদিত সর্বোচ্চ ব্যবহারকারী সংখ্যা এবং হার্ডওয়্যার হ্যাশ থাকবে)।
   - সফটওয়্যার বুট হওয়ার সময় লোকাল পাবলিক কি দ্বারা লাইসেন্স যাচাই করবে।
   - **ফলাফল:** ক্লায়েন্ট যদি পুরো ডকার কন্টেইনার বা ডাটাবেজ কপি করে অন্য কোনো সার্ভারে বা কম্পিউটারে রান করার চেষ্টা করে, হার্ডওয়্যার সিগনেচার অমিল হওয়ার সাথে সাথে সিস্টেম বুট হওয়া বন্ধ হয়ে যাবে।

## ৩. লাভজনকতা ও নিরাপত্তা ফলাফল (Consequences & Benefits)
1. **১০০% আইপি সুরক্ষা:** ক্লায়েন্টের কোনো ডেভেলপার বা থার্ড পার্টি অডিটর মূল কোডবেস দেখতে বা চুরি করতে পারবে না।
2. **চুক্তিহীন পুনঃব্যবহার প্রতিরোধ:** হার্ডওয়্যার লকিংয়ের কারণে এক লাইসেন্স কপি করে অন্য কারখানায় চালানো সম্পূর্ণ অসম্ভব।
3. **এন্টারপ্রাইজ স্ট্যান্ডার্ড কমপ্লায়েন্স:** বিশ্বমানের সেলফ-হোস্টেড সফটওয়্যারগুলোর (SAP, Atlassian, Oracle) সমমানের কমার্শিয়াল সিকিউরিটি নিশ্চিত হবে।
