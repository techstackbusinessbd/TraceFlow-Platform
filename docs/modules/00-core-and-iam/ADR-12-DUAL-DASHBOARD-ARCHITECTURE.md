## ১. প্রসঙ্গ ও সমস্যা বিবৃতি (Context & Problem Statement)
একটি এন্টারপ্রাইজ মাল্টি-কোম্পানি আরএমজি ইআরপি প্ল্যাটফর্মে দুই শ্রেণীর প্রাথমিক ব্যবহারকারী থাকেন:
1. **প্ল্যাটফর্ম ওনার ও কোর সিস্টেম স্কোয়াড:** যাদের মূল কাজ হলো পুরো ইকোসিস্টেমের স্বাস্থ্য পর্যবেক্ষণ, নতুন ক্লায়েন্ট/ফ্যাক্টরি অনবোর্ডিং, লাইসেন্সিং, ব্যাকগ্রাউন্ড কিউ ও সিস্টেম অডিট ট্রেইল পরিচালনা করা।
2. **ক্লায়েন্ট ফ্যাক্টরি অপারেশনাল ইউজার:** (যেমন: ম্যানেজিং ডিরেক্টর, মার্চেন্ডাইজার, কাটিং ইন-চার্জ, সুইং ফ্লোর সুপারভাইজার), যাদের মূল প্রয়োজন লাইভ প্রোডাকশন আউটপুট, লাইন এফিশিয়েন্সি (%), বায়ার অর্ডার ডেলিভারি ট্র্যাকিং এবং কোয়ালিটি (DHU / AQL) মনিটরিং।

উভয় শ্রেণীর ব্যবহারকারীকে একটি একক ড্যাশবোর্ডে নিয়ে আসলে ইন্টারফেসে বিশৃঙ্খলা সৃষ্টি হয়, নিরাপত্তা ঝুঁকি বৃদ্ধি পায় এবং সিস্টেমের ওভারহেড বেড়ে যায়।

## ২. গৃহীত সিদ্ধান্ত (Architectural Decisions)

```
                                [ Authentication Gate ]
                                           │
                       ┌───────────────────┴───────────────────┐
                       ▼                                       ▼
        [ User: ROOT-PLATFORM / Superadmin ]    [ User: Client Factory Tenant ]
                       │                                       │
                       ▼                                       ▼
       /platform/command-center                         /app/dashboard
   ┌─────────────────────────────────────┐   ┌─────────────────────────────────────┐
   │    PLATFORM COMMAND CENTER (Host)   │   │   APPAREL OPERATIONS HUB (Tenant)   │
   ├─────────────────────────────────────┤   ├─────────────────────────────────────┤
   │ • Tenant Companies & Unit Directory │   │ • Live Sewing Line Efficiency (%)   │
   │ • System Infrastructure & Redis Health│ │ • Buyer Order Shipment Tracking     │
   │ • Background Queue & Horizon Worker │   │ • Cutting & Bundle Card Progress    │
   │ • Global Security Logs & Audit Trail│   │ • Floor Quality (DHU / AQL 1.5/2.5) │
   │ • [Switch Tenant / Impersonate View]│   │ • Fabric Stock & Floor Bottlenecks  │
   └─────────────────────────────────────┘   └─────────────────────────────────────┘
```

### [DECISION-01] ইউনিফায়েড কমন লগইন পেজ ও প্রবেশদ্বার (Single Unified Login at `/login`)
- প্ল্যাটফর্ম ওনার, সিস্টেম টিম এবং সাধারণ ফ্যাক্টরি ক্লায়েন্ট—সবার জন্য একটি একক, প্রফেশনাল ও ব্র্যান্ডেড লগইন পেজ থাকবে:
  - **URL:** `/login`
  - কোনো গোপন বা পৃথক ইউআরএল (যেমন: `/platform/login`) রাখার প্রয়োজন নেই।
  - ব্যাকএন্ড অথেনটিকেশন সার্ভার ব্যবহারকারীর ইউজারনেম/ইমেইল যাচাইয়ের সাথে সাথে স্বয়ংক্রিয়ভাবে তার কোম্পানি ও রোল স্ট্যাটাস সনাক্ত করে সঠিক ড্যাশবোর্ডে রাউটিং নির্দেশ করবে।

### [DECISION-02] ডুয়াল পৃথক ওয়ার্কস্পেস রাউট (Dual Workspace Routing)
1. **প্ল্যাটফর্ম ওনার ওয়ার্কস্পেস (`/platform/*`):**
   - শুধুমাত্র `ROOT-PLATFORM` কোম্পানির অন্তর্গত ইউজার অথবা `superadmin` রোলের জন্য সংরক্ষিত।
   - রাউট গার্ড: `PlatformHostGuard` (অন্য যে কেউ ঢুকলে সরাসরি `403 Forbidden` পাবে)।
2. **ক্লায়েন্ট ফ্যাক্টরি ওয়ার্কস্পেস (`/app/*`):**
   - ক্লায়েন্ট ফ্যাক্টরি ও সিস্টার কনসার্ন ব্যবহারকারীদের জন্য ডেডিকেটেড ব্যবসায়িক কার্যক্ষেত্র।

### [DECISION-03] স্মার্ট লগইন রিডাইরেকশন (Context-Aware Auth Response)
লগইন সফল হওয়ার পর অথেনটিকেশন এপিআই রেসপন্সে ব্যবহারকারীর টেন্যান্ট ধরণ চিহ্নিত করে নির্দিষ্ট ড্যাশবোর্ডে পাঠাবে:
```json
{
  "user": {
    "id": "018f-uuid-v7",
    "name": "Platform Superadmin",
    "is_platform_host": true,
    "company": {
      "code": "ROOT-PLATFORM",
      "type": "PLATFORM_HOST"
    },
    "roles": ["superadmin"]
  },
  "dashboard_target": "/platform/command-center"
}
```

### [DECISION-03] টেন্যান্ট সুইচিং ও ইম্পারসোনেশন (Tenant Switch / "View As" Capability)
- প্ল্যাটফর্ম সুপারঅ্যাডমিন সিস্টেমের যেকোনো ফ্যাক্টরি বা সিস্টার কনসার্নের ভিউতে তাৎক্ষণিকভাবে "Switch Tenant" করতে পারবেন।
- ইম্পারসোনেশনের সময় স্ক্রিনের শীর্ষে একটি স্পষ্ট ভিজ্যুয়াল ইন্ডিকেটর (Floating Banner: *"Viewing as Ha-Meem Apparel Unit 1"*) প্রদর্শিত হবে এবং এক ক্লিকে প্ল্যাটফর্ম কমান্ড সেন্টারে ফিরে আসার ব্যবস্থা থাকবে।

## ৩. লাভজনকতা ও নিরাপত্তা সুরক্ষা (Benefits & Safeguards)
1. **ক্লিন ইউএক্স (Clean UX Separation):** ফ্যাক্টরি কর্মীদের ইন্টারফেস টেকনিক্যাল সার্ভার মেট্রিক্স থেকে সম্পূর্ণ মুক্ত থাকবে এবং প্ল্যাটফর্ম ওনারের সামনে পুরো প্ল্যাটফর্মের সার্বিক চিত্র দৃশ্যমান থাকবে।
2. **নিরাপত্তা প্রাচীর (Tenant Wall):** ক্লায়েন্ট কোম্পানির কোনো ইউজার কখনো প্ল্যাটফর্ম হোস্ট ইন্টারফেসে অ্যাক্সেস করতে পারবে না।
3. **দ্রুত গ্রাহক সাপোর্ট (Zero-Friction Support):** ফ্যাক্টরি ফ্লোরে কোনো সমস্যা দেখা দিলে সুপারঅ্যাডমিন সরাসরি টেন্যান্ট ভিউতে ঢুকে সমস্যা নির্ণয় করতে পারবেন।
